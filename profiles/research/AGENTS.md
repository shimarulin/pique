# Agent Instructions

## General

- Give complete answers. Include sources for external data.
- Show reasoning for complex conclusions.
- Use clear labels for each section.
- Do not make assumptions without data.

## Analysis

- Read all relevant files before you answer.
- Show evidence for each claim.
- Separate facts from opinions.
- Use tables to compare options.

## Documentation

- Write summaries that a new reader understands.
- Include links to sources.
- Use consistent formatting.
- Add examples that show application.

## Search

- Use specific search terms.
- Check more than one source for important facts.
- Note the date of each source.
- Tell the user when information is incomplete.
