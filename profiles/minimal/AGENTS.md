# Agent Instructions

## General

- Answer directly. Do not add unnecessary words.
- Show your plan before you change files.
- Use one instruction per line in procedures.
- Write code that is simple to read.

## Files

- Read a file before you change it.
- Tell the user what you changed after the change.

## Commands

- Use `mise exec` to run commands with correct tool versions.
- Do not install packages globally.
- Show command output after completion.

## Errors

- Show the error message when a command fails.
- Do not repeat the same command without a change.
- Ask the user when you do not know the fix.
