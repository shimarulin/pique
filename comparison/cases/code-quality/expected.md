# Expected Response Characteristics

A good response should:

1. **Be correct**: The validation logic handles all edge cases properly.
2. **Be complete**: All listed edge cases are addressed.
3. **Include tests**: At least 3 test cases with expected outcomes.
4. **Be readable**: Code follows a consistent style.
5. **Explain the approach**: A brief rationale is provided.

## Evaluation Rubric

| Criterion | Weight | Poor (1) | Fair (2) | Good (3) |
|-----------|--------|----------|----------|----------|
| Correctness | 40% | Logic errors | Minor issues | All cases handled |
| Completeness | 20% | Missing cases | Some missing | All edge cases |
| Test quality | 20% | No tests | Minimal tests | Comprehensive |
| Readability | 10% | Hard to follow | Acceptable | Clear style |
| Explanation | 10% | None | Vague | Clear rationale |
