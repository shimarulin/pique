## Обзор

pique — коллекция конфигураций пользовательского уровня для Pi Coding Agent и инструмент управления запуском Pi с выбранной конфигурацией.

### Для кого

- Пользователи Pi, которым нужны разные конфигурации для разных задач.
- Те, кто хочет переносить настройки между машинами.
- Те, кто исследует оптимальные конфигурации агента.

### С чего начать

1. Установите pique — см. [README](../../README.ru.md).
2. Просмотрите список профилей: `pique --list`.
3. Запустите Pi с профилем: `pique development`.
4. Изучите [руководство по использованию](usage.md) для деталей.
