# Сравнение профилей

## Сравнение двух профилей

```bash
pique --diff minimal development
```

Или из корня репозитория:

```bash
mise run diff -- minimal development
```

## Вывод

Сравнение показывает:

1. Файлы только в первом профиле.
2. Файлы только во втором профиле.
3. Различия в содержимом общих файлов.

## Когда сравнивать

- Перед созданием нового профиля на основе существующего.
- После изменения общих компонентов.
- При различиях в поведении профилей.
- Перед объединением профилей.

## Понимание различий

| Тип | Значение |
|-----|----------|
| Файл только в A | Первый профиль содержит ресурс, которого нет во втором. |
| Файл только в B | Второй профиль содержит ресурс, которого нет в первом. |
| Изменённое содержимое | Оба содержат файл, но содержимое отличается. |

## Workflow

1. Определите базовый профиль.
2. Сравните со специализированными профилями.
3. Найдите полезные изменения в специализированных профилях.
4. Скопируйте полезные изменения в базовый профиль.
5. Протестируйте базовый профиль.
6. Синхронизируйте общие ресурсы: `mise run sync-shared`.

## Советы

- Сравнивайте минимальный профиль с каждым специализированным.
- Проверяйте идентичность общих ресурсов во всех профилях.
- Ищите непреднамеренные различия.
- Документируйте причину каждого различия.
